Stripe Connect sample

Coaches get paid. Platform takes a fee.

A minimal, end-to-end Stripe Connect flow for Red Seal Rescue: coaches onboard as connected accounts, you publish their coaching packages as products, and tradespeople buy them through a storefront. Each sale uses a destination charge with an application fee, so the platform monetizes every transaction.

1 · Onboard coaches

Create connected accounts and walk them through Stripe-hosted onboarding.

2 · Create products

Publish coaching packages at the platform level, linked to a coach.

3 · Sell

Customers buy via hosted Checkout; funds route to the coach minus the fee.

Before you start

One-time setup (details in the README).
  1. Copy .env.example → .env and paste your test-mode secret key.
  2. npm install then npm run dev.
  3. To test webhooks, run the Stripe CLI listener (see README) and paste the printed whsec_… into .env.
